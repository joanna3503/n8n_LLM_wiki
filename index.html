n8n 是什麼？

n8n 是一款視覺化工作流程自動化工具。你可以在畫布上連接節點，讓資料在不同服務與處理步驟之間流動。

Workflow · 工作流程
把原本需要反覆執行的步驟組成一條可重複執行的流程。
Node · 節點
每個節點負責一項工作，例如接收資料、整理欄位、判斷條件或呼叫外部服務。
適合自動化的工作
優先找重複發生、規則能說清楚，而且輸出可以檢查的工作。

本堂課路線　先看懂節點如何協作，再學 HTTP 串接、條件分流與 AI 分類。

如何挑第一個自動化題目

選擇重複、規則清楚，而且容易驗證的工作。

案例輸入要驗證的成果
表單歸檔表單提交必填資料完整，正確寫入測試表
訂單分流訂單與庫存庫存足與不足各走對應分支
會議助理會議逐字稿輸出決策與行動項目，可回查內容

先讓單一輸入與輸出跑通，再加入其他服務。

操作觀察　先定義成功條件，例如「必填欄位完整時才寫入一列」。用一筆正常輸入和一筆缺欄位的輸入檢查規則，再加通知。

庫存足夠時走哪一條路

查詢庫存後，讓 If 比較庫存與訂購數量。

訂單 quantity→模擬查庫存 stock→If · stock ≥ quantity
合成輸入預期結果
訂購 2 件，庫存 5 件True → 準備出貨
訂購 2 件，庫存 1 件False → 標記待補貨

教學示意。分支只產生狀態。

操作觀察　再測一次庫存剛好等於訂購量的情況。依這個示範的 ≥ 條件，訂購 2 件、庫存 2 件也應走 True。

如何檢查分類與分流

先用預設分類值驗證分支，再單獨驗證模型與草稿。

合成郵件或測試值預期結果
「請問服務報價？」 → 詢價產生待確認的回信草稿
「請你本人確認這份合約」 → 需本人處理產生主旨與摘要
未知分類送人工檢查

預期結果為課程設計。使用外部模型時，送出的郵件內容會傳至該服務。

操作觀察　如果固定分類值走到錯誤分支，先檢查 If 的條件與欄位映射。如果固定值可以正常分流，再檢查模型是否回傳預期的類別。
