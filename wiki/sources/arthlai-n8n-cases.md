# Arth Lai：n8n 應用場景與工作流程

## 設計方式
先選擇排程、外部事件、表單或輪詢，再接上資料處理、條件和動作。原文詳述七種流程，另以速查表補三個情境。

| 場景 | 流程重點 |
| --- | --- |
| LINE 客服 | 收訊息、取出文字、呼叫 Claude、封裝並回傳 |
| 社群發布 | 讀 RSS、去重、產文和配圖、發布並記錄 |
| 每日新聞 | 定時收集、清理與分類摘要、發送和歸檔 |
| 表單歸檔 | 接收提交、驗證欄位、寫入 Notion 和 Sheets、通知 |
| 電商訂單 | 接收訂單、查 ERP 庫存、依庫存分流、更新出貨紀錄 |
| SEO 內容 | 收集搜尋結果與文章結構、生成大綱、交給編輯 |
| 會議助理 | 錄音轉錄、整理決策與行動項目、歸檔並通知 |
| 郵件分類 | 依郵件類別整理歸檔 |
| 庫存預警 | 監控庫存並提醒 |
| CRM 同步 | 同步銷售團隊的客戶資料 |

## 選題與限制
原文建議從表單歸檔開始，再增加 AI 或多平台整合。這些流程可作為架構參考。觸發方式、各平台權限與寫入行為仍需確認，文中的部署、工時和效益估算依實際環境而定。
